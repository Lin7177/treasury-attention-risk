# 源码溯源与发布审查

从 V1–V5 课程目录逐轮盘点实现、训练、验证、审计、作图和打包入口。迁移采用逐文件白名单，只选独立课程研究流程中可检查的 Python 实现、合成测试和去标识参数。Git 从空目录初始化。源代码地图记录源相对位置与迁移前的 SHA-256，仅针对已选课程源代码。

训练及分析实现用于方法复核。历史复跑授权、真实实验锁、内部源身份和本地账本继续随原研究留存。发布适配包括 V2 测试定位 V1 对照、V1 回放入口检查、V5 回放拦截和纯绘图入口。发布副本的配置去掉内部路径、输入标识或数据指纹。固定模型、统计公式和论文数值沿用原口径。

## 本地保留及许可事项

- 实验室或公司项目代码、权属未独立确认的 legacy_reference、冻结副本、参与者辅助探针及依赖原环境的审计脚本保留本地。
- 原始行情、衍生敏感记录、逐日预测、样本账、真实模型权重、拟合变换、输入指纹、内部配置与密钥排除。官方美债数据也留在原已授权环境，外发范围与历史使用范围分别管理。
- V7.1 Word、PDF、Markdown 和图像留在定稿包。GitHub 链接已逐格式检查。第三方库按其各自许可证安装，本仓库无公开再授权声明。
- 如需进一步外发历史快照、历史审计探针或公司依赖，应由对应权利人明确核准范围。变更仓库可见性需要所有者另行明确批准。
